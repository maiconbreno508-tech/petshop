# Casa Pet

Site estático (HTML único) da Casa Pet, pet shop no Village dos Pássaros.

- `index.html`: o site. Edite o bloco `CONFIG` no fim do arquivo (WhatsApp, Instagram, endereço, dias de funcionamento).
- `bot/casapet-bot-whatsapp.json`: configuração do bot de WhatsApp (precisa da API oficial do WhatsApp Business ou plataforma compatível).

## Deploy
Projeto estático: na Vercel, Framework Preset "Other", sem build command e sem output directory.
